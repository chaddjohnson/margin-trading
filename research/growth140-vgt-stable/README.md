# growth140-vgt-stable — Growth 1.4.0 VGT follow-up: archive audit, #4 sensitivity, stable search, chronology

(read only): an audit of its development archive and exclusions, a diagnosis of #4's sensitivity, an independent and
an informed search per entry family, chronological expanding-window tests of the whole selection procedure, and one
frozen comparison on 2025–2026.

in `tools/growth140-vgt-stable/`. Command: `npm run growth140-stable -- <command>`.

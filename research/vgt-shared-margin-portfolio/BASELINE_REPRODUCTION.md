# Baseline reproduction

Every frozen strategy is reproduced three ways before any shared-account or portfolio figure is used: by the
strategy file itself, by the D1-refinement research engine, and by this program's own engine
(`src/shared-margin-portfolio/strategy.ts` + `engine.ts`, which gates fills and transfers positions but must
behave exactly as the files when it runs one strategy alone with a fixed $100,000 principal). Generated by
`npm run shared-margin -- parity --file-dir <dir>`; the machine-readable result is
[`results/parity/parity.json`](results/parity/parity.json).

## 2. What was compared

Against the files' own `trades.csv`, `summary.json` and `daily.csv` (written to a scratch directory by the files
themselves on 2026-10-22), for D1, gross-breakeven D1 and swing-low (file eligibility):

- every trade: entry session, entry minute, entry price, execution label, shares, decision minute, setup kind;
  exit session, exit minute, exit price, reason, execution label, interest, profit; the open trade's unrealized
  profit;
- the totals: net, realized, unrealized, margin interest, daily and minute-sampled maximum drawdown;
- all 2,459 daily mark-to-market values.

Against the D1-refinement engine (`src/d1-refinement/engine.ts` + the trailing-buy-variants accounting), for D1,
gross-breakeven D1, D1 P 8.6%, swing-low (both eligibilities) and Set 2, at 11% and at the 8% / 14% sensitivity
rates and with `next-open` stop fills: the same trade fields, totals, drawdowns and daily marks.

**Result: 27 cases, 0 differences** (tolerance 1e-6 relative). The engine's exit manager is a line-by-line port
of `evaluateBufferedSessionExit` (net-profit stop test re-decided each session, gapped stop at the open, pending
buffered sale, maximum hold at the next trade, the buffer from the hold day, stop-versus-buffer precedence) with
the gross-breakeven latch of the B-B file.

Rate and fill sensitivities of the standalone strategies (fixed $100,000, from `parity.json`):

| D1 and gross-breakeven D1 | $192,142 / $19,183 | $183,044 / $19,331 | $173,945 / $19,479 | $183,757 / $18,983 |
| D1 P 8.6% | $191,941 / $18,916 | $182,842 / $18,990 | $173,744 / $19,064 | $183,557 / $18,641 |

D1 and gross-breakeven D1 stay identical at every rate and fill rule: on this history the net-profit stop never
executed below gross breakeven, so the latch and the re-decided test choose the same sessions. **That is a
property of the observed path, not of the rules**; DEPLOYMENT_RISK.md §5 shows where they would diverge.

## 3. Portfolio-level cross-check

Scenario A (buy and hold, dividends reinvested) ends at **$1,784,588.03**. The committed earlier study
`research/risk-management/vgt-portfolio-margin/` reported $2,379,451 for the same core at $400,000 ($240k VOOG /
$160k VGT) with the same distribution ledger: × 0.75 = $1,784,588.25. The $0.22 difference is the different
treatment of nothing but floating-point order (this program keeps no cash and no monthly interest capitalization
in A, which has no debt). The two ledgers were written independently.

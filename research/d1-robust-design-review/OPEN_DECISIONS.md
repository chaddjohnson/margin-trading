# Open decisions for the user (before any Phase 2 code is written)

Each decision has a recommended default already written into PROPOSED_PROTOCOL.md; choosing an alternative changes the
protocol text before the freeze, never after. Nine decisions; the rest of the design is settled.

| # | Decision | Recommended default | Alternatives | Consequence of the choice |
|---|---|---|---|---|
| **D1** | Neighbourhood definition change: reflection at bounds and common random numbers replace clamping and per-configuration seeds | **Adopt.** All published P50 figures (B1/B4/B5/R1/R4) are recomputed under the new definition before comparison; cross-definition comparisons are forbidden | keep clamping for continuity with the 16-ETF numbers | clamping flatters boundary-sitting vectors (several leaders sit at X = 30%, Y/buffer ≈ 0.1%, P ≈ 19%); keeping it biases the comparison in favour of exactly the configurations under suspicion |
| **D2** | Search objective | **J = P50 − $5,000 × books** with Q25 ≥ 0 as a floor and tie-breaker | J = Q25 − λk (more conservative, noisier at n = 8–16); a weighted blend | Q25-primary would need n ≥ 32 in discovery (≈ 2.5 × compute) to rank reliably; the blend adds a tuned weight |
| **D3** | Timing of the four R1/R4 `all` runs | **after the protocol freeze, before the search** (the user sees them early; frozen rules cannot be influenced) | after the selection freeze and locked confirmation (cleanest; weeks later) | early staging leaves a small implementation-choice bias channel, bounded by the freeze, tests and review; late staging delays the answer the user asked for |
| **D4** | Role of 2024-01-02 → 2026-10-13 | **secondary locked confirmation that can only block** (C1–C4; one run + deterministic confirm) | descriptive only; or a primary confirmation with a positive margin versus B5 | "descriptive only" forgoes a cheap falsification; a positive margin versus an inspected, two-lot-dependent benchmark would be unfair and uninformative |
| **D5** | Universe expansion scope | **Tier 1 (28 symbols) mandatory; Tier 2 (20) if ingestion completes within the ingestion budget; late-inception cohort recorded, not used** | Tier 1 only; or Tier 1 + 2 + a late cohort study | each symbol costs one download (minutes), one import, ≈ 1,045 traces per round and memory (≈ 90 MB); the late cohort would need a separate shorter-horizon protocol because the engine requires one calendar |
| **D6** | Dividend accounting for comparisons | **report both conventions; gates use the symmetric one (`lotDividends: false`); frozen convention reproduces B4/B5's published figures** | frozen convention only | the frozen convention credits VGT lots with cash no other book receives; it biases toward VGT books in gated comparisons by roughly yield × lot-days (small in dollars, but systematic) |
| **D7** | Walk-forward design and the procedure gate | **two folds (search ends 2020-06-30 and 2021-12-31), raw-net ablation arm, G-WF against random-control percentiles (75th/25th) as a go/no-go for any nomination** | folds as reporting only (no gate); or three folds including a pre-crash fold a0 as a gated round | without the gate the study can nominate from a procedure that showed no persistence; fold a0 has too few lots to gate on and is kept descriptive |
| **D8** | Compute tier and parallelism | **full tier if the unit-cost benchmark projects ≤ 36 h single-core or ≥ 6 cores are available for worker threads; else the predeclared fallback (same stages, ≈ 40% budgets)** | fallback from the start | the tier is chosen from unit costs before any result; the fallback preserves breadth (both folds, coverage floor) and drops the seeded arm and halves populations |
| **D9** | Parameter box and data horizon | **keep the existing box (X 8–30%, …) and the existing end date 2026-10-13 for every symbol; label box-constrained finalists; a widened box or newer data is a separately frozen follow-up** | widen X beyond 30% (needs an engine-grid change) and/or download through today for all symbols | widening after seeing leaders at the ceiling is tuning after observation; extending the horizon now would mix the inspected 2024–2026 window with new sessions and would require re-downloading all 16 existing files with `import --replace` or `append` before any search — better done once, after this study, as the first genuine forward test |

Two secondary choices the implementing agent may make without asking (recorded in the protocol): the exact family
clustering thresholds (Jaccard 0.5, funded overlap 0.5, regime correlation 0.7) and the capacity flag threshold (0.10
participation), both predeclared conventions with no outcome dependence.

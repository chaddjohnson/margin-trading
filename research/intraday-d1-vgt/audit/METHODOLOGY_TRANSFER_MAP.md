# Study 8 → Intraday D1 (VGT) methodology transfer map

Written 2026-11-06 (UTC) from the audits in this directory (`STUDY8_AUDIT.md` sha256 `aa488b8f…`, `D1_AUDIT.md`
`313edebb…`, `PRIOR_INTRADAY_AND_INFRA_AUDIT.md` `6f3f4dc3…`) and from direct reading of
`src/study8-expanded-regime-d1/{context,evaluate,stats,fitness,search}.ts`. `S8/` = `src/study8-expanded-regime-d1/`.

**Principle.** Study 8's executable pipeline is reproduced stage for stage, constant for constant, on the single V
(VGT-alone) track. Only three kinds of change are made: (1) pool/multi-book machinery that is inert or meaningless for
one book is removed; (2) the parameter box, grid and radii are re-derived for 1-minute magnitudes (Study 8's box is a
daily, eight-ETF box that does not contain intraday values); (3) the brief excludes walk-forward reoptimization, so
only the fold whose training window equals this study's development window (Study 8's F24: training to 2024-12-31)
is run. No fitness term, gate threshold, budget or stage is invented, loosened or added.

## 2. Box and radii: why they must be re-derived, and how

Study 8's box (`src/multi-etf-d1/context.ts:73-141`) is X 8–30%, Y 0.1–5%, stop 3–15%, hold 3–30 calendar days,
L 20–250 sessions, buffer 0–6%, P 3–20%, W 10–200 sessions. None of these contains the magnitudes an intraday clock
needs (the development-period VGT median 1-minute range is 1–3 bp; median 30-minute drawdown 0.07–0.25%; median
session range 0.7–2.3%, `RESEARCH_RECOVERY.md` data notes). The intraday box is therefore derived (before any search,
from development data and microstructure only) in `PROTOCOL.md` §4, using a geometric grid for scale parameters so
that a radius is a constant *relative* perturbation. Study 8's radii, expressed as fractions of their ranges, are
4–17% of the range (median ≈ 6%); the intraday radii are chosen in that band (±15–20% relative for magnitudes and
durations, ±1 level for the period length).

## 3. What is reported but never selects (as in Study 8)

Half/wide neighbourhoods, PBO, threshold sensitivity, report-only execution settings (0/1/2/3/20 bps, 8% interest,
+10 bps slippage), break-even cost, pro-rata interest, minute-low stop bound, regime and time-of-day diagnostics,
per-year tables. Validation results never reorder, replace or rescue a candidate.

## 4. Discrepancies between Study 8 documents and code that matter here

From `STUDY8_AUDIT.md` §11, resolved in favour of the code: the 40-generation cap is nominal (the 2,048 budget stops
islands at 32 generations of 64); the stagnation/T1 measure is the 2-D (robust/yr, p90 DD) hypervolume; promotion uses
centre-only (−net, DD, −lots); extension islands reuse partition k mod 4; mutation rate 1/d; T2 uses 2,000 resamples;
T2-rescored fits compete in the shortlist pool. All are reproduced as the code does them.

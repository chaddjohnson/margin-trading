# Staged trailing stops (`research/vg-l0-staged-trailing-stop`): disposition — EXCLUDED

**Decision: EXCLUDE from this release.**
- **Branch:** `research/vg-l0-staged-trailing-stop` at `4a89d02a` (= origin) is left exactly as it is: not merged,
  rebased, cherry-picked, edited or deleted.

  fix) neither depends on it nor contains any of its files.

  absent from `main`.

## What a future integration would need (follow-up; the user's decision)

1. **An independent implementation review** of the staged-stop revision by a reviewer that did not write it, recorded
   in the repository, as the B4/B5 pools reviews were.
2. **Preserve the original Growth 1.4.0 path.** For example, put the revision in its own module or version branch, so that
   `riseTrading.ts` v1.4.0 stays byte-identical. Priority 5A's pins then hold, and no completed study's guard is relaxed.
3. **Rebase or merge onto the then-current `main`.** The `package.json` conflict must be resolved, and the CUDA and host
   changes reconciled with the research-date-boundaries tree.
4. **A full §2 GPU acceptance of the combined tree.** Phase 8's record cannot be reused for another tree.

None of this is needed for the core release. The research outcome recommends keeping S1 OFF anyway.

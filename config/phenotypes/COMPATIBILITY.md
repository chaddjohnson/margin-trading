# Phenotype compatibility of the `src/app/` entry points

Generated by `npm run app -- phenotypes matrix config/phenotypes/COMPATIBILITY.md` from
`src/phenotype/strategies.ts`; do not edit by hand.

"Applied" parameters are injected into the declaration of the same name in the unmodified strategy file and
every run proves the strategy read them. "Ignored" parameters are ones the file has no mechanism for; a run
prints them as IGNORED. "Strategy constants" are the file's own mechanism constants, which no phenotype of
the architecture sets: they keep the file's values and every run lists them. Every compatible file also takes
the execution profile's investment per entry, margin interest rate, first eligible date (added to its arming
guard) and data file.
